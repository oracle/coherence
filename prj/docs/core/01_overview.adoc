== Core Improvements

Coherence CE 26.10 includes the following improvements to persistence, service
workers, security, aggregation, and Extend proxies:

* xref:docs/core/01_unified_persistence.adoc[Unified Persistence] describes the
  journal persistence engine, configuration, and migration from Berkeley DB.
* xref:docs/core/02_daemon_pool_dynamic_resizing.adoc[Dynamic Worker Pool Resizing]
  explains how service worker pools adapt to load and how to configure their limits.
* xref:docs/core/03_virtual_daemon_pool.adoc[Virtual Threads for Service Workers]
  describes the virtual worker pool and its configuration and operating requirements.
* xref:docs/core/04_security_hardening.adoc[Security Hardening] covers secure defaults,
  deployment, migration, serialization, and remote execution controls.
* xref:docs/core/05_continuous_aggregation.adoc[Continuous Aggregation] describes
  maintained aggregations and their configuration and operational requirements.
* xref:docs/core/06_extend_proxy_performance.adoc[Extend Proxy Performance]
  explains proxy pipelining and worker-pool configuration.
